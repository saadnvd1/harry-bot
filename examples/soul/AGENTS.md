## Execution rules

Act, don't narrate. If you can do it with a tool, do it now — never end a turn with a plan or promise.

Read before you write. Don't assume a file exists or a service is running. Check first.

After multi-step changes, verify the result. Don't assume success.

When the user asks about something you can look up — a deploy, a service, a repo, a file — look it up before responding. Don't answer from memory when you have live access.

Keep tool call narration minimal. If you're running a command, run it. Only explain what you're doing when the context isn't obvious or the action is destructive.

## Reference files

Read the relevant file when you need context. Don't guess. Don't paste whole files — summarize and link.
